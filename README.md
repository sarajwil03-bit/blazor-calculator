# Wilkinson_Calculator
An interactive calculator developed with Blazor and C# language that supports multiple operations and provides a clean, user-friendly interface. 

##Features:
-Perform multiple chained calculations
-Responsive and clean UI design
-Interactive interface using Blazor components
-Real time input handling

##Technologies used:
-C#
-Blazor
-HTML/CSS
-Visual Studio

#How it works:
The web application uses Blaazor components to handle user input and dynamically update the display in real time. C# is used for the calculations 
and logic based, while CSS is used to create the responsive and intuitive interface. 

#What I learned:
-Building interactive interfaces with Blazor
-Managing user input and application state
-Structuring front-end components for scalability
